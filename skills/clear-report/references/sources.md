# Основания и выбор подхода

Исследование: 3 октября 2026. Аудитория — взрослый пользователь,
которому нужен понятный русскоязычный результат работы агента.

## Что выбрано

Основной подход — **plain language по принципам ISO 24495-1:2023**.
Он связывает понятность с потребностями читателя: нужное содержание,
удобный поиск, ясное изложение и возможность использовать информацию.
Официальная область применения включает большинство письменных языков,
техническое письмо и цифровые тексты. Это подходящая основа для русского
отчета, а не только для английской инструкции.

Из **УТР** взяты однозначность, последовательные термины и ясные действия.
Как дополнительный редакторский ориентир полезен информационный стиль:
убрать канцелярит, повторы и необоснованные оценки, оставляя полезные факты.
Никакой внешний балл читаемости не используется как критерий приемки.

## Сравнение

| Подход | Решение для этого skill |
| --- | --- |
| ISO 24495-1:2023, plain language | Основной подход: применим к русскому и учитывает содержание, структуру и читателя. |
| ASD-STE100 | Источник идеи Карпати и отдельных приемов. Контролируемый английский для технической документации; официальный FAQ исключает общее письмо из области применения. |
| УТР, ГОСТ Р 58049–2017, раздел 8.2 | Дополнительные правила точности. ГОСТ относится прежде всего к переводу эксплуатационной авиационной документации; весь набор правил не переносится в отчет. |
| Информационный стиль Ильяхова / Главред | Практический русский редакторский подход, не стандарт. Автор указывает, что балл Главреда не показывает качество текста. |
| Ясный язык / easy-to-read, СТБ 2595–2021 | Другой профиль доступности, ориентированный на людей, которым трудно читать сложную информацию. Для данной аудитории не выбран как основной подход. |

Обязательное повелительное наклонение и фиксированный лимит слов из УТР
не применяются к обычному отчету. Текст должен сохранять естественный русский,
нужную полноту и точность.

## Источники

- [ISO: официальная карточка ISO 24495-1:2023](https://www.iso.org/standard/78907.html).
  Прочитаны область применения и описание. Примеры стандарта даны на английском,
  но область применения не ограничивается английским языком.
- [Публичный preview ISO через ANSI/Accuris](https://store.accuristech.com/wrc/products/preview/2567849).
  Прочитаны доступные введение, определение, область применения и оглавление
  с четырьмя принципами. Полный платный текст ISO не прочитан и не скопирован.
- [PLAIN: What is plain language?](https://plainlanguagenetwork.org/plain-language/what-is-plain-language).
  Практические ориентиры по содержанию, структуре, оформлению и наглядности.
- [ASD: официальный FAQ STE](https://www.asd-ste100.org/STE_faq.html).
  Назначение, контролируемый словарь и ограничения применения.
- [Текст ГОСТ Р 58049–2017, PDF-зеркало](https://files.stroyinf.ru/Data/661/66114.pdf).
  Прочитаны область применения и раздел 8.2. Актуальный юридический статус
  в реестре Росстандарта отдельно не проверен; ГОСТ используется как источник
  отдельных правил, а не как обязательная норма нашего отчета.
- [Главред: о проекте](https://glvrd.ru/about).
  Авторское описание информационного стиля и ограничений его оценки.
- [РНТБ: СТБ 2595–2021 «Ясный язык»](https://rlst.by/2022/02/15/standart-nedeli-stb-2595-2021-yasnyj-yazyk).
  Прочитана библиотечная аннотация и описание аудитории. Полный стандарт
  не прочитан.
- [W3C WAI: Complex Images](https://www.w3.org/WAI/tutorials/images/complex/).
  Ориентиры для объяснения диаграмм, числовых значений, связей и тенденций.

## Граница соответствия

`references/contract.md` — собственная краткая адаптация. Требования к
реальным изменениям, проверкам и ограничениям добавлены для отчетов агента.
Mermaid, SVG и HTML — выбранные средства, которые ISO не предписывает.

Оценка автора или Jev означает соответствие этому рабочему контракту.
Она не является официальной сертификацией по ISO, УТР или ASD-STE100.
